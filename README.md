# EventForce Management System

A beginner-friendly event management dashboard built with HTML, CSS and JavaScript. This is a portfolio/demo project for Event Planner Solutions.

## Features
- Dashboard cards for events, clients, venues and feedback
- Event schedule with date, type, client, venue and status
- Add and delete clients, venues, vendors, events and feedback
- Responsive layout for desktop and mobile
- Browser local storage for demo records
- Sample records to explore the interface

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. No installation or build command is required.

Optional: use Visual Studio Code with the Live Server extension to preview changes.

## Publish with GitHub Pages
1. Create a public GitHub repository named `EventForce-Management-System`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Project scope
This front-end prototype demonstrates the event management workflow. It does **not** connect to Salesforce or a server-side database. Records are stored in the current browser only and may not appear on another device.
